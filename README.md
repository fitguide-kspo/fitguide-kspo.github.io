# 핏가이드

국민체력100 체력측정 결과를 바탕으로 약점 체력을 채우는 맞춤 운동 처방·기록 웹앱입니다.
국민체육진흥공단(KSPO) 회원정보·국민체력100 API를 제공받으면 가능한 서비스를 보여주기 위한 공모전 출품작입니다.

## 구조

```
index.html                  화면 · 앱 로직
api/kspo/                   "KSPO API" 응답 형태의 데이터 (국민체력100 공공데이터에서 추출)
  members.json              회원 · 체력 5대 요소 (데모 계정 4명)
  fitness-records.json      측정 원천 · 신체계측 · 운동 처방 · 8주 기록
  centers.json              전국 체력인증센터 79곳
  videos.json               운동 가이드 영상 609개
js/config.js                Supabase 연결 정보
js/store.js                 기록 저장 (체크인 · 메모 · 설정)
db/schema.sql               DB 테이블 · 보안 정책
.github/workflows/          Supabase 정지 방지용 주기 요청
```

## 공단 API 연동 시

`index.html` 하단의 `KSPO_API` 주소만 실제 API 엔드포인트로 바꾸면 됩니다.
응답 형식은 `api/kspo/*.json` 과 같게 맞추면 화면 코드는 수정할 필요가 없습니다.

## 기록 저장

- 로그인은 데모 계정(국민체력100 가상 연동)으로만 합니다.
- 체크인 · 메모 · 주 목표 · 센터 · 알림 시간은 계정별로 저장됩니다.
- `js/config.js` 에 Supabase 키가 있으면 DB에, 없으면 브라우저에만 저장됩니다.
- DB는 브라우저마다 익명 사용자로 구분하므로, 같은 데모 계정을 여러 명이 써도 기록이 섞이지 않습니다.
- 설정 탭의 "내 기록 초기화"로 해당 계정의 기록을 지울 수 있습니다.

## 로컬 실행

데이터를 `fetch`로 불러오므로 파일을 직접 열지 말고 간단한 서버로 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다.
